# 离散数学入门

> 小白先读：离散数学是计算机科学的"数学基础课"，研究的是"不连续的东西"——逻辑、集合、图、关系。它不像高数研究连续曲线，但和计算机的关系更紧密。
>
> 学这篇时先抓 3 个问题：为什么计算机专业要学离散数学？命题逻辑和谓词逻辑是什么？图论有什么用？

## 先用一句生活话理解

离散数学像"计算机的语言基础"——计算机只认识 0 和 1，只处理"是"或"否"，只关心"有边"或"没边"。离散数学研究的正是这些"不连续"的东西。

高数研究的是"连续"的世界（曲线、面积、极限），离散数学研究的是"离散"的世界（真/假、有/无、连/断）。后者才是计算机的本质。

## 什么是离散数学？

想象你要设计一个电路：
- **高数**：研究电流怎么连续流动——和电路设计关系不大
- **离散数学**：研究开关只有"开"和"关"两种状态——这才是电路的本质

**简单说**：离散数学是**研究离散结构的数学**，是计算机科学的理论基石。

---

## 离散数学的设计哲学

离散数学的核心问题：**如何用数学语言描述和推理"不连续"的事物？**

主要分支：
- **数理逻辑**：推理的基础
- **集合论**：研究"一堆东西"的性质
- **图论**：研究"关系"和"连接"
- **组合数学**：研究"数数"和"排列"
- **代数结构**：研究运算规则

---

## 核心概念

### 1. 命题逻辑：真与假

**类比**：命题逻辑像电路里的开关——只有"真"（1）和"假"（0）。

- **命题**：能判断真假的陈述句（"今天下雨"是命题，"请关门"不是）
- **与（AND）**：两个都真才真
- **或（OR）**：一个真就真
- **非（NOT）**：取反
- **蕴含（→）**：如果...那么...

这就是编程中 `if (a && b || !c)` 的数学基础。

---

### 2. 集合论：一堆东西的数学

**类比**：集合像一个"袋子"，里面装着各种元素。

- **并集（∪）**：两个袋子合并
- **交集（∩）**：两个袋子共有的
- **补集**：不在袋子里的
- **子集（⊆）**：小袋子在大袋子里

集合论是数据库查询（SQL 的 UNION、INTERSECT）的理论基础。

---

### 3. 关系与函数：事物之间的联系

**类比**：
- **关系**：像"朋友关系"——A 和 B 是朋友
- **函数**：像"自动售货机"——投一个币，出一个饮料

关系的性质：
- **自反性**：自己和自己也有关（自己认识自己）
- **对称性**：A 对 B 有，B 对 A 也有（朋友关系）
- **传递性**：A 对 B 有，B 对 C 有，则 A 对 C 也有（大于关系）

---

### 4. 图论：点和线的世界

**类比**：图论像地图——城市是"点"，公路是"线"。

- **有向图**：线有方向（单行道）
- **无向图**：线没方向（双行道）
- **路径**：从 A 到 B 怎么走
- **连通性**：所有点是否都连在一起

图论是地图导航、社交网络、推荐系统的数学基础。

---

### 5. 组合数学：数数的艺术

**类比**：组合数学像"排列组合"——从 10 个人里选 3 个有几种选法？

- **排列**：有顺序（第一名、第二名、第三名）
- **组合**：没顺序（选 3 个人组队）

组合数学是算法复杂度分析的基础。

---

## 离散数学的应用场景

| 场景 | 用到什么 | 为什么 |
| :--- | :--- | :--- |
| **编程** | 命题逻辑 | if/else 条件判断 |
| **数据库** | 集合论 | SQL 查询操作 |
| **网络路由** | 图论 | 最短路径算法 |
| **密码学** | 数论 | 加密算法 |
| **算法分析** | 组合数学 | 时间复杂度计算 |
| **AI** | 谓词逻辑 | 知识表示与推理 |

## 总结

### 三句话讲清楚离散数学

1. 离散数学研究不连续的数学结构，是计算机科学的理论基础
2. 核心内容：命题逻辑、集合论、图论、关系与函数、组合数学
3. 编程逻辑、数据库查询、图算法、密码学都建立在离散数学之上

### 核心类比

> 离散数学像"计算机的语言基础"——计算机只认识 0 和 1，离散数学研究的正是这些"不连续"的东西。
