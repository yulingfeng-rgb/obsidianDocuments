# 算法设计与分析入门

> 小白先读：算法研究的是"解决问题的步骤和方法"。同样的问题，好的算法快百倍。算法是编程的灵魂，决定了程序的效率。
>
> 学这篇时先抓 3 个问题：什么是算法？怎么评价算法好坏？常见的算法思想有哪些？

## 先用一句生活话理解

算法像菜谱——同样的菜，老厨师的菜谱步骤更优，做得更快更好吃。算法就是"解决问题的最优步骤"。

从家到公司有多条路，有的绕远、有的堵车。算法就是找到最快那条路的方法。

## 什么是算法？

想象你要从一堆扑克牌中找出红桃 A：
- **笨办法**：一张张翻，直到找到（线性查找）
- **聪明办法**：先按花色分类，再在红桃里找（分治）
- **更聪明**：如果牌已排好序，直接跳到中间找（二分查找）

**简单说**：算法是**解决问题的明确步骤**，好的算法让问题更快解决。

## 算法的设计哲学

算法设计的核心问题是：**如何在"时间"和"空间"之间取舍？**

- **时间复杂度**：算法运行需要多少时间
- **空间复杂度**：算法运行需要多少内存

通常时间快的算法占用更多内存，内存省的算法运行更慢。要根据场景选择。

---

## 核心算法思想

### 1. 分治：分而治之

**类比**：要整理一个大房间，先分成几个小区域，每个区域分别整理。

把大问题拆成小问题，小问题解决了，大问题就解决了。

**代表**：归并排序、快速排序

---

### 2. 动态规划：记住过去

**类比**：爬楼梯，到第 10 阶的方法数 = 到第 9 阶 + 到第 8 阶。记住之前的结果，不用重复算。

把问题拆成重叠子问题，记住子问题的答案，避免重复计算。

**代表**：斐波那契数列、背包问题

---

### 3. 贪心：每一步选最优

**类比**：找零钱，每次选最大面额的硬币，最后用的硬币最少。

每一步都选当前最优，希望全局最优。不一定总能得到最优解，但简单高效。

**代表**：霍夫曼编码、Dijkstra 算法

---

### 4. 回溯：试错法

**类比**：走迷宫，走到死胡同就退回来换条路。

尝试每一种可能，不行就退回上一步，直到找到解。

**代表**：八皇后问题、数独

## 时间复杂度速查

| 复杂度 | 含义 | 例子 |
| :--- | :--- | :--- |
| **O(1)** | 常数时间 | 哈希表查找 |
| **O(log n)** | 对数时间 | 二分查找 |
| **O(n)** | 线性时间 | 遍历数组 |
| **O(n log n)** | 线性对数 | 快速排序 |
| **O(n²)** | 平方时间 | 冒泡排序 |
| **O(2ⁿ)** | 指数时间 | 暴力穷举 |

## 算法的应用场景

| 场景 | 用什么 | 为什么 |
| :--- | :--- | :--- |
| **搜索引擎** | 排序算法、索引 | 快速返回结果 |
| **地图导航** | 最短路径算法 | 找到最快路线 |
| **推荐系统** | 协同过滤、图算法 | 找到相似用户/物品 |
| **压缩文件** | 霍夫曼编码 | 用更少的空间存储 |
| **密码学** | 数论算法 | 加密解密 |

## 总结

### 三句话讲清楚算法

1. 算法是解决问题的明确步骤，好的算法让问题更快解决
2. 核心思想：分治、动态规划、贪心、回溯
3. 用时间复杂度衡量算法效率，O(log n) < O(n) < O(n²)
