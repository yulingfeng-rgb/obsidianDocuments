# 计算机网络入门

> 计算机网络研究的是"两台电脑怎么通信"。从你发一条微信到看一个网页，背后都是网络协议在工作。本文讲解网络的分层模型、核心协议与传输机制，帮助理解互联网如何运转。

**关键词**：网络分层、TCP/IP、HTTP、路由、IP 地址、套接字

## 抽象类比

计算机网络像快递系统——你要寄包裹，需要写地址、打包、交给快递公司、经过中转站、最后送达。网络传输也是：数据被打包、经过路由器、最终到达目的地。

你发一条微信，消息被切成小包，经过多个基站和服务器，最终到达对方手机。整个过程和你寄快递几乎一样。

## 什么是计算机网络？

想象你要给远方的朋友寄信：
- **写信**：你的应用层（HTTP、SMTP）
- **装信封**：传输层（TCP、UDP）
- **写地址**：网络层（IP）
- **快递员取件**：数据链路层
- **物理运输**：物理层（网线、光纤）

**简单说**：计算机网络是**让多台电脑互相通信的技术体系**，核心是分层协议。

---

## 计算机网络的设计哲学

网络设计的核心问题是：**如何可靠地传输数据？**

解决方案是**分层**——每层负责一件事，层与层之间互不干扰：
- **应用层**：用户直接打交道的协议（HTTP、FTP）
- **传输层**：保证数据完整到达（TCP）或快速到达（UDP）
- **网络层**：找路，把数据从 A 送到 B（IP）
- **数据链路层**：相邻节点之间的传输
- **物理层**：比特流在物理介质上传输

分层的好处：改一层不影响其他层，就像快递系统改运输工具不影响你写信。

## 核心概念

### 1. TCP vs UDP：快递 vs 平邮

**类比**：
- **TCP**：像顺丰快递，保证送达、有签收确认，但慢一点
- **UDP**：像平邮，扔出去就不管了，快但可能丢

| 特性 | TCP | UDP |
| :--- | :--- | :--- |
| **可靠性** | 保证送达 | 不保证 |
| **速度** | 较慢 | 快 |
| **场景** | 网页、文件传输 | 视频通话、游戏 |

---

### 2. IP 地址：门牌号

**类比**：IP 地址像门牌号，告诉网络"数据送到哪"。

- **IPv4**：`192.168.1.1`，40 亿个地址，快用完了
- **IPv6**：`2001:0db8:...`，地址多到用不完

**DNS**：域名系统，把 `google.com` 翻译成 IP 地址，像电话簿。

---

### 3. HTTP：浏览器和服务器说的话

**类比**：HTTP 像点菜——你（浏览器）看菜单（网页），告诉服务员（服务器）"我要这个"，服务员把菜（数据）端上来。

- **GET**：获取数据（"给我看看菜单"）
- **POST**：提交数据（"我要点菜"）
- **状态码**：200 成功、404 找不到、500 服务器出错

---

### 4. 路由器：快递中转站

**类比**：路由器像快递中转站，决定包裹下一站往哪送。

数据包从你的电脑出发，经过多个路由器，最终到达目标服务器。每个路由器根据 IP 地址选择最优路径。

## 网络的应用场景

| 场景 | 用什么 | 为什么 |
| :--- | :--- | :--- |
| **浏览网页** | HTTP/HTTPS | 浏览器和服务器通信 |
| **发邮件** | SMTP/POP3 | 邮件传输协议 |
| **视频通话** | UDP | 实时性要求高 |
| **文件传输** | FTP/TCP | 要求完整可靠 |
| **远程登录** | SSH | 安全远程控制 |

3. TCP 保证可靠传输，UDP 追求速度，IP 负责寻址路由

## 面试速答

### Q: TCP和UDP的区别？分别适用什么场景？
A: TCP面向连接、可靠传输、有序到达，适合网页、文件传输等要求完整的场景；UDP无连接、不保证可靠、速度快，适合视频通话、游戏等要求实时的场景。类比：TCP是顺丰快递（保证送达有签收），UDP是平邮（扔出去就不管）。

### Q: 三次握手为什么不能是两次？
A: 两次握手只能确认客户端的接收能力，无法确认服务端的接收能力。如果客户端的旧连接请求延迟到达服务端，服务端会误开连接浪费资源。第三次握手让双方都确认彼此的收发能力，防止无效连接。

### Q: 在浏览器输入URL到页面展示，发生了什么？
A: DNS解析域名得到IP→TCP三次握手建立连接→发送HTTP请求→服务器处理并返回响应→浏览器解析HTML/CSS/JS渲染页面→TCP四次挥手断开。整个过程涉及应用层、传输层、网络层、链路层的协同。

### Q: HTTP和HTTPS有什么区别？
A: HTTPS = HTTP + SSL/TLS加密。HTTP明文传输，数据可被中间人窃听篡改；HTTPS在传输层加密，保证机密性、完整性和身份认证，但握手开销略大。现在网站基本都用HTTPS。

### Q: 为什么网络要分层？
A: 分层让每层只负责一件事，层与层之间通过接口交互，互不干扰。好处是：改一层不影响其他层、便于标准化、便于排错。类比：快递系统改运输工具（飞机换高铁）不影响你写信的方式。
