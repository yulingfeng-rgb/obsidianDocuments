# 计算机网络入门

> 计算机网络研究的是"两台电脑怎么通信"。从你发一条微信到看一个网页，背后都是网络协议在工作。理解网络，才能理解互联网怎么运转。

## 先用一句生活话理解

计算机网络像快递系统——你要寄包裹，需要写地址、打包、交给快递公司、经过中转站、最后送达。网络传输也是：数据被打包、经过路由器、最终到达目的地。

你发一条微信，消息被切成小包，经过多个基站和服务器，最终到达对方手机。整个过程和你寄快递几乎一样。

## 什么是计算机网络？

想象你要给远方的朋友寄信：
- **写信**：你的应用层（HTTP、SMTP）
- **装信封**：传输层（TCP、UDP）
- **写地址**：网络层（IP）
- **快递员取件**：数据链路层
- **物理运输**：物理层（网线、光纤）

**简单说**：计算机网络是**让多台电脑互相通信的技术体系**，核心是分层协议。

---

## 计算机网络的设计哲学

网络设计的核心问题是：**如何可靠地传输数据？**

解决方案是**分层**——每层负责一件事，层与层之间互不干扰：
- **应用层**：用户直接打交道的协议（HTTP、FTP）
- **传输层**：保证数据完整到达（TCP）或快速到达（UDP）
- **网络层**：找路，把数据从 A 送到 B（IP）
- **数据链路层**：相邻节点之间的传输
- **物理层**：比特流在物理介质上传输

分层的好处：改一层不影响其他层，就像快递系统改运输工具不影响你写信。

## 核心概念

### 1. TCP vs UDP：快递 vs 平邮

**类比**：
- **TCP**：像顺丰快递，保证送达、有签收确认，但慢一点
- **UDP**：像平邮，扔出去就不管了，快但可能丢

| 特性 | TCP | UDP |
| :--- | :--- | :--- |
| **可靠性** | 保证送达 | 不保证 |
| **速度** | 较慢 | 快 |
| **场景** | 网页、文件传输 | 视频通话、游戏 |

---

### 2. IP 地址：门牌号

**类比**：IP 地址像门牌号，告诉网络"数据送到哪"。

- **IPv4**：`192.168.1.1`，40 亿个地址，快用完了
- **IPv6**：`2001:0db8:...`，地址多到用不完

**DNS**：域名系统，把 `google.com` 翻译成 IP 地址，像电话簿。

---

### 3. HTTP：浏览器和服务器说的话

**类比**：HTTP 像点菜——你（浏览器）看菜单（网页），告诉服务员（服务器）"我要这个"，服务员把菜（数据）端上来。

- **GET**：获取数据（"给我看看菜单"）
- **POST**：提交数据（"我要点菜"）
- **状态码**：200 成功、404 找不到、500 服务器出错

---

### 4. 路由器：快递中转站

**类比**：路由器像快递中转站，决定包裹下一站往哪送。

数据包从你的电脑出发，经过多个路由器，最终到达目标服务器。每个路由器根据 IP 地址选择最优路径。

## 网络的应用场景

| 场景 | 用什么 | 为什么 |
| :--- | :--- | :--- |
| **浏览网页** | HTTP/HTTPS | 浏览器和服务器通信 |
| **发邮件** | SMTP/POP3 | 邮件传输协议 |
| **视频通话** | UDP | 实时性要求高 |
| **文件传输** | FTP/TCP | 要求完整可靠 |
| **远程登录** | SSH | 安全远程控制 |

---

## 总结

### 三句话讲清楚计算机网络

1. 计算机网络是让多台电脑互相通信的技术体系
2. 核心是分层协议：应用层、传输层、网络层、链路层、物理层
3. TCP 保证可靠传输，UDP 追求速度，IP 负责寻址路由

### 核心类比

> 计算机网络像快递系统——数据被打包、经过中转站、最终送达目的地。
