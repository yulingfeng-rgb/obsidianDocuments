# Linux 入门

> 小白先读：Linux 是一个操作系统，和 Windows 一样管理电脑硬件和软件。它是服务器、手机（Android）、嵌入式设备的首选，程序员几乎都要和它打交道。
>
> 学这篇时先抓 3 个问题：Linux 和 Windows 有什么区别？为什么服务器都用 Linux？命令行是什么？

## 先用一句生活话理解

Linux 像一辆手动挡卡车——没有 Windows 那么花哨的界面，但稳定、高效、可控。专业司机（程序员）都爱开它。

Windows 像自动挡轿车，开箱即用、界面友好；Linux 像手动挡卡车，启动要懂点原理，但跑起来又快又稳。

## 什么是 Linux？

想象你要管理一家餐厅：
- **Windows**：像连锁快餐店，总部（微软）帮你决定一切，你照着做就行
- **Linux**：像独立餐厅，你是老板，想怎么装修、怎么经营都行

**简单说**：Linux 是一个**开源、免费、稳定**的操作系统，服务器和开发者的首选。

---

## Linux 的设计哲学

Linux 诞生于 1991 年，设计者是 Linus Torvalds。核心理念：
- **一切皆文件**：硬件、进程、设备都用文件表示
- **小工具组合**：每个工具只做一件事，组合起来威力巨大
- **命令行优先**：图形界面是可选的，命令行才是核心

---

## 核心概念

### 1. 命令行：和电脑对话

**类比**：Windows 像触屏手机，点一点就行；Linux 像语音助手，你要用文字告诉它做什么。

常用命令：
- `ls` — 列出文件
- `cd` — 切换目录
- `cp` — 复制文件
- `mv` — 移动/重命名
- `rm` — 删除文件
- `cat` — 查看文件内容

---

### 2. 文件系统：树状结构

**类比**：Linux 的文件系统像一棵倒过来的树，根目录是 `/`。

```
/
├── home/        # 用户主目录
├── etc/         # 配置文件
├── var/         # 可变数据（日志等）
├── usr/         # 用户程序
└── tmp/         # 临时文件
```

---

### 3. 权限管理：谁能做什么

**类比**：Linux 像一栋办公楼，每个人有不同的门禁卡。

- **r（读）**：能看文件
- **w（写）**：能改文件
- **x（执行）**：能运行文件

`chmod 755 file` — 设置文件权限

---

### 4. 包管理：应用商店

**类比**：包管理器像手机的应用商店，一键安装软件。

- **apt**（Ubuntu/Debian）：`apt install nginx`
- **yum**（CentOS）：`yum install nginx`
- **pacman**（Arch）：`pacman -S nginx`

---

## Linux 的应用场景

| 场景 | 例子 | 为什么用 Linux |
| :--- | :--- | :--- |
| **服务器** | Web、数据库 | 稳定、免费、性能好 |
| **嵌入式** | 路由器、智能设备 | 可定制、资源占用小 |
| **开发环境** | 程序员日常 | 工具链完善 |
| **Android** | 手机系统 | 基于 Linux 内核 |

---

## 总结

### 三句话讲清楚 Linux

1. Linux 是开源免费的操作系统，服务器和开发者的首选
2. 命令行是核心，一切皆文件，权限管理严格
3. 稳定、高效、可定制，但学习曲线比 Windows 陡

### 核心类比

> Linux 像手动挡卡车——没有 Windows 花哨，但稳定高效可控。
