# Swift 入门

> 小白先读：Swift 是苹果为 iOS/macOS 开发打造的现代编程语言，替代了老旧的 Objective-C。它语法简洁、安全，是苹果生态开发的首选。
>
> 学这篇时先抓 3 个问题：Swift 和 Objective-C 有什么区别？可选类型是什么？Swift 为什么安全？

## 先用一句生活话理解

Swift 像苹果精心打造的"iPhone"——设计精美、体验流畅、但只能在苹果生态里用。它是 Objective-C 的"现代化重生"。

如果说 Objective-C 是一辆老式跑车（快但难开），Swift 就是同款车的"智能电动版"——更快、更安全、更好开。

## 什么是 Swift？

想象你要开发一款 App：
- **Java/Kotlin**（Android）：像盖一栋普通住宅，选择多、灵活
- **Swift**（iOS）：像盖一栋苹果风格的别墅，设计规范、体验统一
- **React Native/Flutter**：像盖一栋"万能房"，想住哪都行

**简单说**：Swift 是苹果推出的**现代、安全、高效**的编程语言，iOS/macOS 开发的首选。

---

## Swift 的设计哲学

Swift 诞生于 2014 年，由苹果推出。目标是"**替代 Objective-C，让 iOS 开发更现代**"。

Swift 的核心信条：
- **安全**：编译时检查，减少运行时崩溃
- **现代**：语法简洁，支持函数式编程
- **快速**：性能接近 C++
- **交互**：可以和 Objective-C 混用

Swift 吸收了 Rust、Python、C# 等语言的优点，是一门"集大成者"。

---

## 核心概念

### 1. 可选类型：向"空指针崩溃"说再见

**类比**：
- **Objective-C**：你打开盒子，可能是空的，打开前自己检查
- **Swift**：盒子分两种——"一定有东西"和"可能有东西"，编译器帮你检查

Swift 用 `?` 标记可选类型：
- `String` 一定有值
- `String?` 可能为空（可选类型）

想操作可选值？必须先"解包"。编译器强制你处理空的情况，运行时就不会崩溃。

---

### 2. 值类型：复制而不是引用

**类比**：
- **引用类型**（类）：你和朋友看同一份文件，你改了朋友也看到了
- **值类型**（结构体）：你给朋友复印了一份，你改你的，不影响朋友

Swift 鼓励使用值类型（结构体），避免共享状态带来的副作用。这让代码更可预测。

---

### 3. 协议导向编程：接口优先

**类比**：你叫了一辆车，不在乎是轿车还是 SUV，能坐就行。

Swift 的"协议"像一份能力清单：
- 定义"能做什么"，不定义"怎么做"
- 任何类型都可以实现协议
- 代码更灵活、更易测试

## Swift 的优缺点

### 优点
- **安全**：编译时检查，减少运行时错误
- **现代**：语法简洁，支持函数式编程
- **快速**：性能接近 C++
- **苹果支持**：iOS 开发首选
- **开源**：社区活跃

### 缺点
- **生态封闭**：主要用于苹果生态
- **就业市场小**：不如 Java/Kotlin 岗位多
- **版本变化快**：语法经常变动，老代码要迁移
- **跨平台不成熟**：Linux/Windows 支持有限

## Swift vs Kotlin

| 维度 | Swift | Kotlin |
| :--- | :--- | :--- |
| **平台** | 苹果生态 | Android + JVM |
| **语法** | 简洁 | 简洁 |
| **空安全** | 可选类型 | 可选类型 |
| **性能** | 接近 C++ | 接近 Java |
| **跨平台** | 弱 | 强（JVM） |
| **适合场景** | iOS/macOS | Android/后端 |

2. 可选类型机制让代码更安全，减少运行时崩溃
3. iOS/macOS 开发的首选，苹果生态的"官方语言"
