# CSS 入门

> 小白先读：CSS 不是编程语言，是"样式语言"，用来定义网页长什么样。它是前端开发的三驾马车之一（HTML + CSS + JavaScript），负责美化网页。
>
> 学这篇时先抓 3 个问题：CSS 是什么？选择器是什么？盒模型是什么？

## 先用一句生活话理解

CSS 像房子的"装修风格"——HTML 决定了哪里是客厅、哪里是卧室，CSS 决定了墙面什么颜色、地板什么材质、灯光怎么打。

如果把网页比作一个人：HTML 是骨架，CSS 是皮肤、衣服、化妆，JavaScript 是肌肉和表情。

## 什么是 CSS？

想象你要装修房子：
- **HTML**：房子的结构——哪里是墙、哪里是门
- **CSS**：装修风格——墙面颜色、地板材质、灯光效果
- **JavaScript**：智能家居——自动开关门、自动调节灯光

**简单说**：CSS 是**层叠样式表**，用来定义网页的视觉样式，让网页变得好看。

---

## CSS 的设计哲学

CSS 诞生于 1996 年，目标是"**把内容和样式分离**"。

CSS 的核心信条：
- **分离**：HTML 管内容，CSS 管样式
- **层叠**：多个样式规则可以叠加，后面的覆盖前面的
- **选择器**：精准控制"谁"长什么样
- **响应式**：一套代码适配多种屏幕

CSS 让网页从"能用"变成"好看"。

---

## 核心概念

### 1. 选择器：找到"谁"要变样式

**类比**：选择器像点名——"穿红衣服的那位"、"坐在第一排的同学"。

CSS 用选择器找到要改样式的元素：
- `p` 所有段落
- `.highlight` 所有 class 为 highlight 的元素
- `#header` id 为 header 的元素

```css
p { color: blue; }           /* 所有段落变蓝 */
.highlight { background: yellow; }  /* 高亮元素黄底 */
#header { font-size: 24px; }      /* 头部字号24px */
```

---

### 2. 盒模型：每个元素都是一个盒子

**类比**：每个 HTML 元素都是一个快递盒子。

盒模型由内到外：
- **内容**：盒子里装的东西
- **内边距（padding）**：盒子和内容之间的缓冲
- **边框（border）**：盒子的外壳
- **外边距（margin）**：盒子和其他盒子之间的距离

```css
.box {
  width: 200px;        /* 内容宽度 */
  padding: 20px;       /* 内边距 */
  border: 1px solid;   /* 边框 */
  margin: 10px;        /* 外边距 */
}
```

---

### 3. 布局：盒子怎么摆放

**类比**：布局像家具摆放——横着放、竖着放、重叠放。

常用布局方式：
- **Flexbox**：一维布局，横着或竖着排
- **Grid**：二维布局，横竖都排
- **浮动（float）**：老式布局，文字环绕图片

```css
/* Flexbox：横着排，居中 */
.container {
  display: flex;
  justify-content: center;
  align-items: center;
}
```

## CSS 的应用场景

| 场景 | 例子 | 为什么用 CSS |
| :--- | :--- | :--- |
| **网页美化** | 所有网站 | 定义视觉样式 |
| **响应式设计** | 手机/平板/电脑 | 一套代码多端适配 |
| **动画效果** | 过渡、动画 | 让网页动起来 |
| **打印样式** | 打印友好 | 网页打印成 PDF |

---

## CSS 的优缺点

### 优点
- **样式分离**：内容和样式解耦
- **强大选择器**：精准控制元素
- **响应式**：适配多种屏幕
- **动画**：不需要 JavaScript 就能做动画

### 缺点
- **层叠复杂**：样式冲突难调试
- **学习曲线**：属性太多，记不住
- **不是编程语言**：没有逻辑、不能编程
- **浏览器兼容**：不同浏览器表现不同

---

## CSS vs 其他"语言"

| 维度 | HTML | CSS | JavaScript |
| :--- | :--- | :--- | :--- |
| **是什么** | 标记语言 | 样式语言 | 编程语言 |
| **作用** | 定义结构 | 定义样式 | 定义行为 |
| **能编程吗** | 不能 | 不能 | 能 |
| **类比** | 骨架 | 皮肤 | 肌肉 |

## 总结

### 三句话讲清楚 CSS

1. CSS 是层叠样式表，用来定义网页的视觉样式
2. 用选择器找到元素，用属性定义样式
3. 不是编程语言，负责让网页变得好看

### 核心类比

> CSS 像房子的"装修风格"——HTML 决定了哪里是客厅，CSS 决定了墙面什么颜色、地板什么材质。
