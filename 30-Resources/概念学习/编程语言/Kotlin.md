# Kotlin 入门

> 小白先读：Kotlin 是 Java 的"现代化升级版"，完全兼容 Java 但语法更简洁。它是 Android 开发的官方推荐语言，也适合后端开发。
>
> 学这篇时先抓 3 个问题：Kotlin 解决了 Java 的什么痛点？空安全是什么？为什么 Google 推荐 Kotlin？

## 先用一句生活话理解

Kotlin 像 Java 的"精装修版"——房子结构一样，但装修更现代、更人性化。你不用重新学怎么盖房子，只需要学新的装修技巧。

如果说 Java 是自动挡商务车，Kotlin 就是同款车的"智能升级版"——加了自动泊车、车道保持，开起来更舒服。

## 什么是 Kotlin？

想象你要装修房子：
- **Java** 像毛坯房，什么都要自己装，规矩多
- **Kotlin** 像精装房，基础设施一样，但开发商帮你把细节处理好了
- **Swift** 像另一栋楼，风格完全不同

**简单说**：Kotlin 是一门**兼容 Java、语法简洁、空安全**的编程语言，Android 开发的官方推荐。

---

## Kotlin 的设计哲学

Kotlin 诞生于 2011 年，由 JetBrains 开发。他们的目标是"**做一个更好的 Java**"。

Kotlin 的核心信条：
- **兼容 Java**：可以直接调用 Java 代码，无缝迁移
- **简洁**：同样的功能，代码量比 Java 少很多
- **空安全**：编译时防止空指针异常
- **现代**：支持函数式编程、扩展函数等现代特性

2017 年 Google 宣布 Kotlin 为 Android 开发首选语言，Kotlin 迎来爆发。

---

## 核心概念

### 1. 空安全：向空指针说再见

**类比**：
- **Java**：你打开盒子，可能是空的，打开前自己检查
- **Kotlin**：盒子分两种——"可能有东西"和"一定有东西"，编译器帮你检查

Kotlin 的类型系统区分可空和不可空：
- `String` 一定有值
- `String?` 可能为空

想操作可空变量？必须先处理空的情况。编译器强制你这么做，运行时就不会崩溃。

---

### 2. 数据类：一行搞定

**类比**：
- **Java**：定义一个数据类，要写一堆 getter/setter/equals/hashCode
- **Kotlin**：一行 `data class` 搞定

```kotlin
data class User(val name: String, val age: Int)
```

编译器自动生成所有样板代码。

---

### 3. 扩展函数：给类加新功能

**类比**：你买了一辆车，想加个新功能。不用拆开重新设计，直接"外挂"一个功能。

Kotlin 可以给任何类添加新方法，不用修改原类：

```kotlin
fun String.sayHello() = "Hello, $this"
"Kotlin".sayHello() // "Hello, Kotlin"
```

## Kotlin 的应用场景

| 场景 | 例子 | 为什么用 Kotlin |
| :--- | :--- | :--- |
| **Android 开发** | 手机 App | Google 官方推荐 |
| **后端服务** | Spring Boot | 兼容 Java 生态，代码更简洁 |
| **多平台** | Kotlin Multiplatform | 一套代码跑多端 |
| **脚本** | 构建脚本 | Gradle 支持 Kotlin DSL |

---

## Kotlin 的优缺点

### 优点
- **兼容 Java**：无缝调用 Java 代码，迁移成本低
- **简洁**：代码量比 Java 少很多
- **空安全**：编译时防止空指针
- **现代**：支持函数式编程、协程等现代特性
- **Google 支持**：Android 官方推荐

### 缺点
- **编译慢**：比 Java 编译慢
- **学习曲线**：Java 程序员要适应新语法
- **生态依赖 Java**：本质还是 JVM 生态
- **多平台不成熟**：Kotlin Multiplatform 还在发展中
