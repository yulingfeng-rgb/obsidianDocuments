# HTML 入门

> 小白先读：HTML 不是编程语言，是"标记语言"，用来定义网页的结构和内容。是前端开发三驾马车之一（HTML + CSS + JavaScript），是所有网页的基础。

## 先用一句生活话理解

HTML 像房子的"钢筋骨架"——决定了哪里是客厅、哪里是卧室、哪里放门放窗。没有 HTML，网页就不存在。

如果把网页比作一个人：HTML 是骨架，CSS 是皮肤和衣服，JavaScript 是肌肉和神经。

## 什么是 HTML？

想象你要写一封信：
- **HTML**：信的结构——哪里是标题、哪里是正文、哪里是签名
- **CSS**：信的样式——字体多大、颜色什么、排版怎样
- **JavaScript**：信的功能——点击能回复、能转发、能动画

**简单说**：HTML 是**超文本标记语言**，用来定义网页的结构和内容，是所有网页的基础。

---

## HTML 的设计哲学

HTML 诞生于 1993 年，设计者是 Tim Berners-Lee。目标是"**让科学家能分享文档**"。

HTML 的核心信条：
- **语义化**：标签要有意义，`<header>` 就是头部，`<article>` 就是文章
- **结构化**：内容要有层次，标题、段落、列表各司其职
- **可访问**：让搜索引擎、屏幕阅读器都能理解

HTML 不是编程语言，没有逻辑、没有循环，只是"标记"内容是什么。

---

## 核心概念

### 1. 标签：内容的"身份证"

**类比**：标签像超市商品的分类标签——"这是水果"、"这是蔬菜"。

HTML 用标签告诉浏览器"这是什么"：
- `<h1>` 这是大标题
- `<p>` 这是段落
- `<img>` 这是图片
- `<a>` 这是链接

```html
<h1>我的网站</h1>
<p>欢迎来到我的网站！</p>
<img src="photo.jpg" alt="照片">
```

---

### 2. 嵌套：俄罗斯套娃

**类比**：HTML 元素像俄罗斯套娃，一层套一层。

```html
<div>
  <h1>标题</h1>
  <p>这是<strong>重要</strong>的内容</p>
</div>
```

`<div>` 里套着 `<h1>` 和 `<p>`，`<p>` 里又套着 `<strong>`。

---

### 3. 属性：标签的"附加信息"

**类比**：属性像商品的详细说明——"颜色：红色"、"尺寸：大号"。

```html
<a href="https://example.com" target="_blank">点击访问</a>
<img src="photo.jpg" alt="照片描述" width="300">
```

`href`、`src`、`alt` 都是属性，给标签提供额外信息。

## HTML 的应用场景

| 场景 | 例子 | 为什么用 HTML |
| :--- | :--- | :--- |
| **网页开发** | 所有网站 | 网页的基础结构 |

| **电子书** | EPUB 格式 | 基于 HTML |
| **桌面应用** | Electron | 用 HTML 写界面 |

---

## HTML 的优缺点

### 优点
- **简单**：语法直观，上手容易
- **通用**：所有浏览器都支持
- **语义化**：让内容更有意义
- **可访问**：搜索引擎友好

### 缺点
- **不是编程语言**：没有逻辑、不能编程
- **样式有限**：需要 CSS 来美化
- **静态**：需要 JavaScript 来交互

---

## HTML vs 其他"语言"

| 维度 | HTML | CSS | JavaScript |
| :--- | :--- | :--- | :--- |
| **是什么** | 标记语言 | 样式语言 | 编程语言 |
| **作用** | 定义结构 | 定义样式 | 定义行为 |
| **能编程吗** | 不能 | 不能 | 能 |
| **类比** | 骨架 | 皮肤 | 肌肉 |

1. HTML 是超文本标记语言，用来定义网页的结构和内容
2. 用标签告诉浏览器"这是什么"——标题、段落、图片、链接
3. 不是编程语言，是所有网页的基础
