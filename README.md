## 文档格式规范

所有概念学习与工作效率文档遵循统一结构：

1. **标题**（`# 文档标题`）
2. **引用简介**（`> 一句话说明是什么、解决什么、本文讲什么`）
3. **关键词**（`**关键词**：词1、词2、词3、词4、词5`，3-6 个，置于开头而非文末）
4. **抽象类比**（`## 抽象类比`，1-2 段生活类比，让小白秒懂）
5. **正文**（按章节展开，概念文档重类比与原理，工作效率文档重使用步骤与技巧）
6. **面试 Q&A 与如何给别人讲**（概念文档标配）

约定：

- 架构图必须用 Mermaid，不用纯文本图
- 多用列表少用表格，避免 emoji
- 内部链接用 Obsidian 双链或相对路径
- 外部链接用 web URL
