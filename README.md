# 个人知识库

> 基于 Obsidian 的个人知识管理系统，按主题目录组织，记录技术学习、工作效率与个人思考。

## 目录结构

```
├── 学习/          # 技术学习资料（8 个一级目录）
├── 工作效率/      # AI 工具、文档工具、图表工具等
├── 个人成长/      # 个人思考与感悟（问我、人物）
├── Assets/        # 附件目录（图片等，Obsidian 统一存放位置）
├── 未归档/        # 未归档内容的临时存放处（已加入 .gitignore，不纳入版本管理）
├── .obsidian/     # Obsidian 配置（主题、插件）
└── README.md
```

## 文档格式规范

所有概念学习与工作效率文档遵循统一结构：

1. **标题**（`# 文档标题`）
2. **引用简介**（`> 一句话说明是什么、解决什么、本文讲什么`）
3. **关键词**（`**关键词**：词1、词2、词3、词4、词5`，3-6 个，置于开头而非文末）
4. **抽象类比**（`## 抽象类比`，1-2 段生活类比，让小白秒懂）
5. **正文**（按章节展开，概念文档重类比与原理，工作效率文档重使用步骤与技巧）
6. **面试 Q&A 与如何给别人讲**（概念文档标配）

约定：

- 架构图必须用 Mermaid，不用纯文本图
- 多用列表少用表格，避免 emoji
- 内部链接用 Obsidian 双链或相对路径
- 外部链接用 web URL
