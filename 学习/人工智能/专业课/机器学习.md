# 机器学习

> 机器学习（Machine Learning）是让机器从大量数据中自动寻找规律，并用这些规律对未来或未知数据做出预测或决策的技术。它解决的是"规则太多写不过来、人工定不动"的问题——不靠手动编写"如果…就…"的规则，而是让算法自己从样本中归纳规则。本文将系统介绍机器学习的三大范式、经典算法、训练流程与评估方法。

**关键词**：监督学习、无监督学习、特征工程、过拟合、梯度下降

## 抽象类比

机器学习就像一个学生通过大量做题总结题型套路的过程：做过的题越多、总结的规律越准，遇到新题时就越能举一反三。老师不直接告诉学生"遇到什么题就用什么公式"，而是让学生从一道道例题里自己悟出方法——这就是"数据驱动、自动找规律"。

再打个比方：传统编程是"厨师照菜谱做菜"，人写好步骤、机器照着执行；机器学习则是"厨师尝了一百道菜后自己琢磨出配方"，人只给原料和反馈，机器自己总结出做法。

## 一、机器学习的三大范式

机器学习按"学习方式"可分为三大类，每种都对应一种日常学习场景：

- **监督学习**：有标准答案，类比"做题对答案"
  - 每条样本都带标签（标准答案）
  - 模型目标：让预测尽可能接近答案
  - 典型任务：分类、回归
- **无监督学习**：无标准答案，类比"自由归类书架"
  - 数据没有标签，需要模型自己发现结构
  - 模型目标：发现数据内在的聚类或结构
  - 典型任务：聚类、降维
- **强化学习**：试错得奖励，类比"训练宠物"
  - 由 Agent（智能体）、环境、奖励信号三要素组成
  - 通过不断试探环境、根据奖励调整策略
  - 策略从随机探索逐步收敛到最优
  - 典型应用：游戏 AI、机器人控制、推荐策略

## 二、监督学习的核心任务

监督学习是最常见的机器学习类型，根据预测结果的类型可分为：

- **分类（Classification）**：预测离散类别标签
  - 例如：垃圾邮件识别（垃圾 / 正常）
  - 例如：图像分类（猫 / 狗 / 鸟）
  - 输出是有限的几个类别
  - 评估指标常用准确率、精确率、召回率
- **回归（Regression）**：预测连续数值
  - 例如：房价预测（输出具体价格）
  - 例如：温度预测（输出具体度数）
  - 输出是连续实数
  - 评估指标常用 MSE、RMSE、R 方

## 三、经典算法

下面列举机器学习中最常用的经典算法，每个算法都有一句话定位：

监督学习算法：

- **线性回归**：用一条直线（或超平面）拟合数据，适合预测连续值
- **逻辑回归**：名字虽叫回归，实际用于二分类，输出概率
- **决策树**：通过一系列"如果…就…"规则做判断，像一棵问答树
- **随机森林**：多棵决策树投票，比单棵树更稳定、更抗过拟合
- **支持向量机 SVM**：找一条最宽的"隔离带"分隔不同类别
- **K 近邻 KNN**：看周围最近的 K 个邻居是什么，就把自己归为多数那一类
- **朴素贝叶斯**：基于贝叶斯定理，假设特征相互独立，常用于文本分类

无监督学习算法：

- **K-Means 聚类**：把数据划分成 K 个簇，每个簇围绕一个中心
- **PCA 降维**：在尽量保留信息的前提下压缩特征维度
- **DBSCAN**：基于密度的聚类，能发现任意形状的簇，不需要预设簇数

## 四、模型训练流程

一个典型的机器学习项目流程如下：

```mermaid
flowchart LR
    A[数据收集] --> B[数据预处理]
    B --> C[特征工程]
    C --> D[划分训练/验证/测试集]
    D --> E[模型训练]
    E --> F[模型评估]
    F --> G[部署上线]
    F -.效果不佳.-> C
```

- 数据收集：从业务系统、日志、爬虫等渠道获取原始数据
- 数据预处理：清洗异常值、处理缺失、归一化
- 特征工程：从原始数据构造对预测有用的字段
- 划分数据集：训练集学、验证集调参、测试集最终评估
- 模型训练：用算法在训练集上拟合参数
- 模型评估：用测试集看模型在未见数据上的真实表现
- 部署上线：将模型集成进业务系统，持续监控效果

## 五、关键概念

- **特征与标签**
  - 特征：描述样本的输入属性，如房屋面积、楼层
  - 标签：要预测的目标，如房价
- **训练集 / 验证集 / 测试集**
  - 训练集：模型"上课学知识"
  - 验证集：模型"模拟考"，用来调参
  - 测试集：模型"期末考"，仅最后用一次
- **过拟合与欠拟合**
  - 过拟合：类比"死记硬背考题"，训练分高、测试分低
  - 欠拟合：类比"压根没学会"，连训练分都很低
- **偏差与方差**
  - 偏差：模型本身的预测与真实值的系统性差距
  - 方差：模型对不同训练集敏感程度
  - 偏差高 ≈ 欠拟合，方差高 ≈ 过拟合
- **损失函数与梯度下降**
  - 损失函数：衡量预测与真实值差距的"扣分规则"
  - 梯度下降：类比"蒙眼下山"，每次沿最陡方向走一步，逐步逼近最低点
- **正则化**
  - L1 正则化：倾向于让部分权重变为 0，可用于特征选择
  - L2 正则化：让权重整体变小，模型更平滑
  - 作用：抑制过拟合

## 六、模型评估指标

分类任务常用指标：

- 准确率（Accuracy）：所有预测中正确的比例
- 精确率（Precision）：预测为正的样本中真正为正的比例
- 召回率（Recall）：真正为正的样本中被预测为正的比例
- F1 值：精确率与召回率的调和平均，兼顾两者
- ROC 曲线：以假阳率为横轴、真阳率为纵轴的曲线
- AUC：ROC 曲线下方面积，越接近 1 越好
- 回归任务常用指标：均方误差 MSE、均方根误差 RMSE、平均绝对误差 MAE、R 方

## 七、数据挖掘与机器学习的关系

- 数据挖掘偏商业应用：从海量业务数据中挖掘有价值的模式
- 机器学习偏算法研究：研究让机器自动学习的方法
- 二者交叉点：数据挖掘常借助机器学习算法作为工具
- 区别举例：数据挖掘更关注"能不能发现商业机会"，机器学习更关注"算法准不准、泛化好不好"
- 联系：很多数据挖掘流程的"建模"环节，本质上就是在用机器学习

## 八、常见应用场景

- 推荐系统：电商商品推荐、视频内容推荐、音乐推荐
- 金融风控：信用评分、欺诈检测、反洗钱
- 医疗诊断：疾病预测、影像辅助诊断、用药推荐
- 自然语言处理：情感分析、文本分类、垃圾过滤
- 计算机视觉：人脸识别、车牌识别、工业缺陷检测
- 销售预测：库存管理、需求预测、营销响应预测
- 智能交通：路径规划、流量预测、信号灯优化
- 工业制造：设备故障预警、良品率预测、能耗优化

## 面试速答

- Q1：过拟合怎么解决？
  - 增加训练数据，让模型见多识广
  - 使用正则化（L1 / L2）限制权重
  - 使用 Dropout、剪枝等结构技巧
  - 简化模型，降低容量
  - 提前停止训练（Early Stopping）
  - 使用交叉验证更稳健地评估
- Q2：监督学习和无监督学习的区别？
  - 监督学习有标签，无监督学习无标签
  - 监督学习目标明确（预测标签），无监督学习目标自由（发现结构）
  - 监督学习易评估准确率，无监督学习难有统一指标
  - 监督学习典型任务是分类和回归，无监督学习典型任务是聚类和降维
- Q3：梯度下降是什么？
  - 一种通过迭代更新参数来最小化损失函数的优化方法
  - 每次根据损失函数对参数的梯度（导数）反向更新参数
  - 学习率决定步长，太大可能震荡，太小收敛慢
  - 常见变体：批量梯度下降、随机梯度下降、小批量梯度下降
- Q4：监督学习和强化学习有什么区别？
  - 监督学习有标签，从标准答案学；强化学习无标签，从环境奖励学
  - 监督学习一次输入一次输出；强化学习是序列决策，要考虑长期回报
  - 监督学习典型任务是分类回归；强化学习典型应用是游戏 AI、机器人控制
- Q5：精确率和召回率有什么区别？
  - 精确率：预测为正的样本中真正为正的比例（查准率）
  - 召回率：真正为正的样本中被预测为正的比例（查全率）
  - 二者通常此消彼长，需按场景权衡：医疗诊断偏召回（别漏诊），垃圾过滤偏精确（别误杀）

## 端到端实践与评估

- **实践任务**：从线性/树模型基线开始完成一个端到端分类或回归项目。
- **评估要求**：用交叉验证、置信区间和错误切片比较模型，而非只报单一平均指标。
- **失败边界**：先检查数据与标签，再调模型；复杂模型无法修复目标定义错误和分布漂移。

实验记录至少包含问题定义、数据来源与版本、基线、配置、指标、失败样本和结论适用范围。只有结果可复现、误差可解释，模型改进才有可信度。
