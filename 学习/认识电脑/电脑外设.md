# 电脑外设与接口知识

> 键盘、鼠标、显示器接口、蓝牙、串口……这些每天都在用的东西，很多人只知其然不知其所以然。本文系统梳理常见外设的原理、用法与快捷键，以及 USB、HDMI、蓝牙、串口等连接方式的知识。

**关键词**：键盘、快捷键、鼠标、USB、HDMI、蓝牙、串口

## 抽象类比

电脑是大脑，外设就是它与外界交互的"感官和手脚"：键盘是嘴（输入指令）、鼠标是手指（指点操作）、显示器接口是"眼睛的连线"、网口是"耳朵听世界"、蓝牙是"隔空喊话"、串口是工程师用的"对讲机"——一次性只和一个人慢悠悠地聊，但胜在稳定可靠、门槛极低。

## 一、键盘

### 1.1 常见布局与配列

标准键盘分四个键区：主键区（字母数字）、功能键区（F1-F12）、编辑键区（方向键、Home/End 等）、数字小键盘。

常见配列（尺寸）：

- **104 键（全尺寸）**：四区齐全
- **87 键（TKL，去小键盘）**：节省桌面空间，程序员主流选择
- **75% / 60% 配列**：只保留主键区 + 方向键（75%）或更少（60%），F 区和编辑键需要组合键实现

### 1.2 键盘类型

- **薄膜键盘**：硅胶碗 + 薄膜电路，便宜、静音、手感一般
- **机械键盘**：每颗键独立轴体。常见轴体手感：青轴（段落感强、咔哒响、吵）、茶轴（轻微段落、均衡）、红轴（直上直下、轻、适合长时间打字）、黑轴（重、回弹快、游戏向）
- **静电容**：手感细腻稳定，价格高

### 1.3 修饰键：组合键的原理

所有快捷键都由**修饰键 + 主键**构成，理解修饰键就理解了一半快捷键：

| 修饰键 | 定位 |
| --- | --- |
| Ctrl / Cmd | 主要操作键（复制、粘贴、保存） |
| Shift | 大写、反方向、扩展选择（Shift+End 选到行尾） |
| Alt | 菜单与窗口级操作（Alt+Tab 切窗口） |
| Win | 系统级操作（Win+E 打开资源管理器） |
| Fn | 笔记本上组合多媒体功能（亮度、音量） |

### 1.4 Windows 必会快捷键

**通用操作**

| 快捷键 | 作用 |
| --- | --- |
| Ctrl+C / X / V | 复制 / 剪切 / 粘贴 |
| Ctrl+Z / Y | 撤销 / 恢复 |
| Ctrl+S / Ctrl+Shift+S | 保存 / 另存为 |
| Ctrl+F / Ctrl+H | 查找 / 替换 |
| Ctrl+A | 全选 |
| Alt+Tab / Win+Tab | 切换窗口 / 任务视图 |
| Win+D | 显示桌面 |
| Win+E | 资源管理器 |
| Win+L | 锁屏 |
| Win+I | 系统设置 |
| Win+Shift+S | 截图（区域选择） |
| Ctrl+Shift+Esc | 直接打开任务管理器 |

**文本编辑（效率翻倍的一组）**

| 快捷键 | 作用 |
| --- | --- |
| Home / End | 跳到行首 / 行尾 |
| Ctrl+Home / Ctrl+End | 跳到文档开头 / 结尾 |
| Ctrl+← / → | 按词跳转 |
| Shift+以上任意 | 选中光标到目标的全部内容 |
| Delete | 向后删除（Fn+Delete 在笔记本上） |

**终端 / 开发者常用**

- Tab：命令/路径补全（不要一遍遍敲全名）
- Ctrl+C / Ctrl+V：终端内复制粘贴（Windows Terminal 支持）
- Ctrl+R：搜索历史命令（bash/PowerShell）
- Ctrl+L 或 `clear`：清屏
- Ctrl+C：中断正在运行的程序
- Ctrl+D：退出当前会话（EOF）
- 上/下方向键：翻历史命令

**Win 组合进阶**：Win+V（剪贴板历史，先启用）、Win+句号（emoji 面板）、Win+上下方向（窗口最大化/还原）、Win+左/右方向（窗口分屏贴靠）。

### 1.5 打字与护腕

- 手腕悬空、手指放在 ASDF / JKL; 基准键位上，盲打是长期效率投资
- 键盘支架或掌托可缓解腕部压力；长时间敲击建议红轴或薄膜静音轴

## 二、鼠标

### 2.1 结构与按键

- **左键**：选择、确认；**右键**：上下文菜单
- **滚轮**：滚动页面；**滚轮按下（中键）**：在新标签页打开链接 / 关闭标签页（浏览器利器）
- **侧键**：默认"前进/后退"，浏览网页和资源管理器非常好用，游戏里常自定义

### 2.2 关键参数

- **DPI/CPI**：每移动一英寸报告的点数，数值越高越"灵敏"。办公 800-1600 足够，游戏看需求
- **回报率（Polling Rate）**：每秒向电脑报告位置的次数，常见 125Hz / 500Hz / 1000Hz，越高越跟手、越耗电
- **双击速度、滚轮行数**：在系统设置里可调

### 2.3 无线连接方式对比

| 方式 | 延迟 | 便利性 | 说明 |
| --- | --- | --- | --- |
| 有线 | 无 | 需理线 | 最稳，游戏高端主流 |
| 2.4G 接收器（USB dongle） | 极低 | 占一个 USB 口 | 无线游戏鼠标首选 |
| 蓝牙 | 略高 | 多设备切换方便 | 办公主流，可连手机/平板 |

三模鼠标（有线 + 2.4G + 蓝牙）是现在的通用解。

## 三、常见接口

### 3.1 接口速查表

| 接口 | 外观/特征 | 主要用途 | 关键参数 |
| --- | --- | --- | --- |
| USB-A | 扁平矩形，只能一面插 | 键鼠、U 盘、接收器 | USB 2.0：480 Mbps；3.2 Gen1：5 Gbps；Gen2：10 Gbps（常见蓝色舌头） |
| USB-C（Type-C） | 椭圆，正反可插 | 充电、数据、视频、音频全能 | 速率同上至 USB4 40 Gbps；支持 PD 快充（最高 240W）、DP Alt Mode 视频输出 |
| USB-B / Mini-USB / Micro-USB | 方形 / 小梯形 / 小梯形 | 打印机 / 老设备 / 老手机 | 逐步淘汰，嵌入式开发板仍常见 Micro-USB |
| HDMI | 梯形，带卡扣感 | 音视频一线到显示器/电视 | HDMI 2.0：4K@60Hz；2.1：4K@120Hz / 8K@30Hz；支持 ARC 音频回传 |
| DisplayPort（DP） | 梯形，一侧有缺角 | 电脑接高刷显示器 | DP 1.4：4K@120Hz+；DP 2.1：更高；支持菊花链（MST） |
| VGA / DVI | 蓝色 15 针 / 宽扁白口 | 老显示器、投影 | 模拟信号 / 数字信号，正被淘汰 |
| RJ45（网口） | 宽扁带卡扣 | 有线网络 | 百兆 / 千兆 / 2.5G / 10G 网卡 |
| 3.5mm 音频孔 | 圆孔 | 耳机、麦克风 | 三段（耳机）/ 四段（带麦，CTIA/OMLC 分线序） |
| SD / TF 卡槽 | 大 / 小卡片 | 相机、无人机、行车记录仪 | 注意 UHS-I（金手指单排）与 UHS-II（双排）速度差异 |
| DC 电源口 | 圆柱形 | 老笔记本、显示器供电 | 注意电压电流参数匹配 |

### 3.2 USB-C 的"全能"与"陷阱"

USB-C 只是一个**物理形状**，内部支持什么功能要看设备规格：

- **只充电**：很多千元数据线只有 2.0 速率
- **PD 快充**：需要线材和两头设备都支持，常见 65W / 100W / 140W
- **视频输出（DP Alt Mode）**：笔记本一根线接显示器要确认有此功能
- **雷电（Thunderbolt）**：USB-C 形状里的"满血版"，40 Gbps，可外接显卡坞、双 4K 屏

**排错口诀**：C 口设备不充电/不识别/不显示，先换原装线，再查是否支持对应协议——十有八九是线的问题。

### 3.3 集线器与扩展坞

- **Hub（集线器）**：只扩展 USB 口，几十块
- **扩展坞（Dock）**：扩展 USB + HDMI + 网口 + SD + PD 充电，适合笔记本接口少的场景；选购注意"笔记本一个 C 口是否支持视频输出"，否则 HDMI 无效

## 四、蓝牙

### 4.1 是什么

蓝牙是基于 2.4GHz 频段的短距离无线通信标准，用于耳机、键鼠、手柄、音箱等设备连接，典型有效距离约 10 米。

### 4.2 版本演进

| 版本 | 关键特性 |
| --- | --- |
| 4.0 | 引入 BLE（低功耗蓝牙），手环/传感器的基础 |
| 5.0 | 传输距离和速度翻倍，支持一拖二 |
| 5.2 | LE Audio 低功耗音频，音质与续航双赢 |
| 5.3 / 5.4 | 更省电、连接更稳定 |

### 4.3 经典蓝牙 vs BLE

- **经典蓝牙**：持续大流量传输——耳机音频（A2DP）、文件传输、蓝牙串口（SPP）
- **BLE（低功耗）**：间歇小数据——手环、传感器、键盘鼠标、信标

### 4.4 常见用途与排错

- 用途：无线耳机、键鼠、手柄、打印机、手机传文件、嵌入式调试（蓝牙串口透传）
- 排错：配对失败 → 删除配对记录重连；耳机音质差 → 检查是否切到了"免提（HFP）"模式（通话协议音质差，A2DP 才是高音质）；延迟高 → 游戏/视频场景优先 2.4G 接收器或有线；干扰 → 2.4GHz 频段拥挤，远离 Wi-Fi 路由器和微波炉

## 五、串口（UART）

### 5.1 是什么

串口（UART，通用异步收发传输器）是最基础、最古老也是嵌入式领域至今不可替代的通信方式——开发板调试输出、烧录固件、和模块（GPS、ESP8266）对话都靠它。Windows 上表现为"COM 口"。

### 5.2 关键参数（两端必须一致，否则乱码）

| 参数 | 常见值 |
| --- | --- |
| 波特率 | 9600、115200（最常用） |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | 无 |
| 接线 | TX↔RX 交叉连接，共 GND |

### 5.3 USB 转串口

现代电脑没有物理串口，用 USB 转串口芯片桥接：

- 常见芯片：**CH340**（国产、便宜、需装驱动）、CP2102、FT232
- 插上后到"设备管理器 → 端口（COM 和 LPT）"确认 COM 编号
- 终端工具：PuTTY、MobaXterm、VS Code Serial Monitor、Arduino IDE 串口监视器

### 5.4 与其他协议的关系

UART 是点对点的异步串行链路；I2C、SPI 是板内多器件总线；RS232/RS485 是 UART 的电气标准延伸（工业长距离）。深入内容见《[通信协议](通信协议.md)》与《[串口](串口.md)》。

## 六、选购与使用建议

- **键鼠**：办公选静音（薄膜或红轴）+ 三模无线；游戏看重回报率和有线/2.4G
- **扩展坞**：先确认笔记本 C 口支持 DP Alt Mode 和 PD，再决定是否买"全功能"
- **线材**：好设备配好线，长距离 HDMI/DP 优先 8K 认证线；USB 延长线尽量短
- **蓝牙 vs 2.4G**：要低延迟选 2.4G，要多设备切换选蓝牙
- **调试场景**：常玩开发板，备一根 CH340 的 USB-TTL 线（杜邦线母对母），十几块钱解决大问题

## 常见问题速答

- Q：U 盘插 USB 3.0 口速度没变快？
  A：U 盘本身可能只有 2.0 速率，瓶颈在盘不在口。

- Q：显示器接 HDMI 没声音？
  A：声音输出设备没切换——右下角音量图标选"数字输出（HDMI）"。

- Q：蓝牙耳机打游戏延迟大？
  A：蓝牙音频协议延迟高，用 3.5mm 有线或 2.4G 无线耳机。

- Q：串口输出全是乱码？
  A：九成是波特率不匹配，把终端波特率改成和设备一致（先试 115200）。

- Q：笔记本键盘 Fn 键反了（按 F1 变亮度调节）？
  A：BIOS 里找 "Fn Lock" 或 "Hotkey Mode" 设置，或 Fn+Esc 切换。

- Q：Win 键游戏中总误触？
  A：游戏键盘的 Win Lock 功能，或用 PowerToys 的 Keyboard Manager 禁用。

## 系统实践与验收

- **最小系统**：为现有设备画连接拓扑，标出接口形状、协议、带宽、供电与转接链路。
- **验收方法**：逐段替换线材、端口和设备定位问题，并记录协商速率与供电能力。
- **边界与风险**：接口外形相同不代表功能相同；USB-C 尤其要确认数据、视频、充电协议和线材规格。

实践记录应包含版本、连接或部署拓扑、关键配置、原始现象、测量方法和恢复步骤，使别人能够在不同环境中复现并判断差异。
