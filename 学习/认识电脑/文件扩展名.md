# 文件扩展名

> 文件扩展名是文件名中用来标识文件类型的（如 `.txt`、`.exe`），操作系统和应用程序靠它判断用什么方式打开。

**关键词**：文件扩展名、文件格式、后缀名、文件类型

## 抽象类比

文件扩展名就像“信封上的标签”——邮递员（操作系统）看到“急件”“航空”等标签，就知道该走哪个通道、用哪种方式处理。文件扩展名告诉系统这个文件是程序、文档、图片还是视频，从而选择对应的打开方式。

## 程序与安装包

### Windows

- `.exe` —— 可执行程序，就是你平时双击打开就能用的软件本体
- `.msi` —— 软件安装包，双击后会启动安装向导帮你装软件
- `.msix` / `.appx` —— 新版 Windows 应用安装包，微软商店里的应用就用这种格式
- `.msp` —— Windows 安装包补丁，用来给已安装的软件打补丁更新
- `.scr` —— Windows 屏幕保护程序，本质上就是一个特殊的 `.exe` 文件
- `.cpl` —— Windows 控制面板项，双击打开系统设置页面，比如"鼠标属性"、"显示设置"
- `.msc` —— 微软管理控制台管理单元，如 `services.msc`、`devmgmt.msc`

### Linux

- `.deb` —— Debian/Ubuntu 软件包，用 `dpkg -i` 或 `apt install ./xxx.deb` 安装
- `.rpm` —— Red Hat/CentOS/Fedora 软件包，用 `rpm -i` 或 `dnf install` 安装
- `.pkg.tar.zst` —— Arch Linux 软件包，用 `pacman -U` 安装
- `.AppImage` —— 免安装可执行程序，下载后 `chmod +x` 加执行权限即可直接运行，类似 Windows 的"绿色版"
- `.snap` —— Ubuntu Snap 软件包，用 `snap install` 安装，自带依赖隔离
- `.flatpak` / `.flatpakref` —— 跨发行版通用软件包，沙箱运行，用 `flatpak install` 安装
- `.run` —— 自解压安装脚本，常见于 NVIDIA 驱动、安装程序等，`chmod +x` 后直接运行

### macOS / iOS

- `.dmg` —— macOS 磁盘镜像，双击挂载后拖入 Applications 即完成安装
- `.pkg` —— macOS 安装包，双击启动安装向导，类似 Windows 的 `.msi`
- `.app` —— macOS 应用程序，就是一个文件夹，右键可以"显示包内容"看里面结构
- `.ipa` —— iOS 应用安装包，装到 iPhone/iPad 上的文件格式

## 库与驱动

### Windows

- `.dll` —— 动态链接库，里面装着很多程序都要共用的代码，程序运行时需要它，不能删
- `.sys` —— 系统驱动文件，属于 Windows 内核的一部分，普通用户不要动它
- `.lib` —— 静态链接库（Windows 版），编译时链接进可执行文件
- `.manifest` —— 应用程序清单文件，声明依赖的组件和权限

### Linux

- `.so` —— 共享对象（Shared Object），相当于 Linux 版的 `.dll`，程序运行时动态加载
- `.ko` —— 内核模块（Kernel Object），Linux 内核的驱动文件，用 `insmod` 或 `modprobe` 加载
- `.a` —— 静态链接库，编译时直接打包进程序，运行时不再需要
- `.o` —— 目标文件，编译器生成的中间产物，链接后变成可执行文件

### macOS

- `.dylib` —— macOS 动态库，相当于 Linux 的 `.so`
- `.kext` —— macOS 内核扩展，相当于 Linux 的 `.ko`，系统级驱动
- `.framework` —— macOS 框架目录，包含库、头文件和资源

## 脚本与自动化

- `.bat` / `.cmd` —— Windows 批处理脚本，把很多条命令写在一个文本文件里，双击就能按顺序自动执行
- `.ps1` —— PowerShell 脚本，比 `.bat` 更强大的自动化工具
- `.vbs` —— 用 VBScript 语言写的脚本文件，Windows 可以直接运行，但常被恶意利用，要小心来历不明的 `.vbs` 文件
- `.sh` —— Shell 脚本，Linux/macOS 下的自动化脚本，相当于 Windows 的 `.bat`
- `.bash` —— Bash 脚本，常见于 Linux 系统
- `.zsh` —— Zsh 脚本，macOS 默认 Shell

## 配置文件

### 通用配置

- `.ini` —— Windows 配置文件，用纯文本记录程序或系统的设置项，可以用记事本打开编辑
- `.conf` —— Linux 配置文件，各种服务和程序的配置都用这种纯文本格式
- `.cfg` —— 通用配置文件，和 `.ini` 类似但格式更自由
- `.config` —— .NET 应用配置文件，C# 项目常见
- `.plist` —— macOS 属性列表文件，macOS 的配置格式，相当于 Windows 的 `.ini`
- `.reg` —— Windows 注册表文件，双击导入后会修改系统配置，操作前建议先备份
- `.inf` —— Windows 安装信息文件，告诉系统怎么安装驱动程序，一般不直接运行
- `.htaccess` —— Apache 服务器的目录配置文件，用于 URL 重写、权限控制等
- `.editorconfig` —— 编辑器配置文件，统一不同编辑器和 IDE 的代码风格
- `.env` —— 环境变量配置文件，常用于记录密钥、数据库连接等敏感信息（不要提交到 Git）

### Linux 系统配置

- `.service` —— Linux systemd 服务单元文件，定义后台服务的启动方式
- `.timer` —— systemd 定时器单元，类似 cron 的定时任务
- `.desktop` —— Linux 桌面快捷方式文件，相当于 Windows 的 `.lnk`，放在 `/usr/share/applications/` 下

### 现代格式

- `.yaml` / `.yml` —— 配置文件格式，比 JSON 更易读，开发中很常用
- `.toml` —— 另一种配置文件格式，简洁清晰，Go/Rust 项目常用
- `.hcl` —— HashiCorp 配置语言，Terraform 等工具使用

## 文档类

- `.txt` —— 纯文本文件，没有任何格式，用记事本就能打开，最基础的文件类型
- `.pdf` —— 版式文档，排版固定不变，适合分享和打印，几乎每台电脑都能打开
- `.md` —— 轻量级标记语言，用简单符号就能写出排版美观的文档，程序员和笔记爱好者常用
- `.tex` —— LaTeX 排版文档，学术论文和数学公式常用
- `.docx` —— Word 文档，日常写报告、论文最常用的格式
- `.doc` —— 老版 Word 文档格式（2003 及以前），现在基本被 `.docx` 取代
- `.xlsx` —— Excel 表格文件，用来做数据统计、报表
- `.xls` —— 老版 Excel 格式，和 `.doc` 一样是旧时代的产物
- `.pptx` —— PPT 演示文稿，做汇报、展示用的幻灯片
- `.ppt` —— 老版 PPT 格式
- `.csv` —— 逗号分隔的表格数据，可以用 Excel 打开，常用于数据导入导出
- `.tsv` —— 制表符分隔的表格数据
- `.rtf` —— 富文本格式，跨平台的"带格式文字"，Word 和写字板都能打开
- `.epub` —— 电子书格式，可以在手机或阅读器上看书
- `.chm` —— Windows 编译的 HTML 帮助文件，老软件的帮助文档常用
- `.pages` —— Apple Pages 文档，Mac/iPad 上的文字处理软件专用格式
- `.numbers` —— Apple Numbers 表格，Mac 版 Excel
- `.key` —— Apple Keynote 演示文稿，Mac 版 PPT
- `.odt` —— LibreOffice 文本文档，开源办公套件格式
- `.ods` —— LibreOffice 表格文件
- `.odp` —— LibreOffice 演示文稿

## 图片类

- `.jpg` / `.jpeg` —— 最常见的照片格式，体积小，适合日常分享
- `.png` —— 支持透明背景的图片，图标、截图常用这种格式
- `.gif` —— 动图格式，表情包和简单动画都用它
- `.webp` —— Google 推出的图片格式，比 jpg 更小，网页上越来越常见
- `.avif` —— 新一代图片格式，基于 AV1 视频编码，压缩率极高，网页端逐步普及
- `.heic` / `.heif` —— 苹果高效图片格式，iPhone 拍照默认保存格式，比 jpg 更小但兼容性稍差
- `.bmp` —— Windows 早期的图片格式，不压缩所以文件很大，现在很少用了
- `.ico` —— Windows 图标文件，就是桌面快捷方式上显示的那个小图标
- `.icns` —— macOS 图标文件
- `.tiff` —— 高质量图片格式，印刷和专业摄影领域用得多
- `.psd` —— Photoshop 工程文件，保留图层和编辑信息，设计师常用
- `.ai` —— Illustrator 矢量图文件，平面设计行业常用
- `.xcf` —— GIMP 工程文件，开源版 Photoshop
- `.raw` —— 相机原始数据文件，保留最多细节，专业摄影师拍完再修图用
- `.cr2` / `.nef` / `.arw` —— 佳能/尼康/索尼相机的 RAW 格式
- `.dds` —— DirectX 纹理格式，游戏开发常用，显卡直接支持
- `.hdr` —— 高动态范围图像，3D 渲染和环境光照常用
- `.svg` —— 矢量图，放大多少倍都不会模糊，网页图标常用

## 字体类

- `.ttf` —— TrueType 字体，Windows 和 macOS 都通用，最常见
- `.otf` —— OpenType 字体，比 TTF 更先进，支持更多排版特性
- `.woff` / `.woff2` —— Web 字体格式，专为网页加载优化，压缩率高
- `.ttc` —— 字体集合文件，一个文件包含多个字体

## 音频类

- `.mp3` —— 最普及的音乐格式，几乎所有设备都能播放
- `.wav` —— 未压缩的音频，音质好但文件大，常用于录音和音频编辑
- `.flac` —— 无损压缩音频，音质和 wav 一样但文件更小，音乐发烧友爱用
- `.aac` —— 比 mp3 更高效的格式，苹果设备默认用它
- `.ogg` —— 开源音频格式，音质好且免费，游戏和流媒体中常见
- `.opus` —— 新一代开源音频格式，延迟低音质好，语音通话和直播越来越爱用
- `.m4a` —— 苹果常用的音频容器格式，里面通常装的是 AAC 编码的音频
- `.wma` —— 微软自家的音频格式，现在用得少了
- `.mid` / `.midi` —— 电子乐器数字接口文件，记录的是音符而不是声音，电子音乐制作常用
- `.aiff` —— 苹果的未压缩音频格式，类似 wav
- `.cue` —— 光盘镜像索引文件，常和整轨无损音乐配合使用
- `.m3u` / `.m3u8` —— 播放列表文件，HLS 流媒体常用 `.m3u8`

---

## 视频类

- `.mp4` —— 最通用的视频格式，手机、电脑、网页都能播
- `.mkv` —— 开源视频容器，能装多条音轨和字幕，高清电影常用
- `.mov` —— 苹果的视频格式，iPhone 拍的视频就是这个格式
- `.webm` —— 专为网页设计的视频格式，HTML5 原生支持，YouTube 在用
- `.avi` —— 微软的老牌视频格式，兼容性好但压缩率一般
- `.ts` —— 常用于数字电视广播，也见于高清视频源文件
- `.m4v` —— 苹果的视频格式，和 mp4 很像，iTunes 里下载的视频通常是这个格式
- `.mpeg` / `.mpg` —— MPEG 标准视频格式
- `.m2ts` —— 蓝光光盘视频文件
- `.hevc` / `.h265` —— 高效率视频编码，4K 视频常用

---

## 压缩包类

- `.zip` —— 最常见的压缩格式，Windows 自带就能解压，通用性最强
- `.rar` —— 压缩率比 zip 高，需要用 WinRAR 等软件解压
- `.7z` —— 开源压缩格式，压缩率很高，需要 7-Zip 等软件支持
- `.tar` —— Linux 下常用的打包格式，只打包不压缩
- `.gz` —— Linux 下的压缩格式，通常和 tar 一起用，写成 `.tar.gz`
- `.tgz` —— `.tar.gz` 的简写，Linux 下很常见
- `.xz` —— 压缩率比 gz 更高的格式，Linux 内核源码分发常用
- `.bz2` —— bzip2 压缩格式，压缩率比 gz 好一些但速度慢一点
- `.zst` —— Zstandard 压缩格式，Facebook 开发，速度快压缩率也高，越来越流行
- `.lz4` —— 极速压缩格式，解压速度极快，常用于大数据和内核日志
- `.cab` —— 微软的压缩包格式，常见于系统安装或驱动包中
- `.br` —— Brotli 压缩，主要用于网页传输

## 网页与网络类

- `.html` —— 网页文件，你在浏览器里看到的每个页面都是它
- `.css` —— 样式表，控制网页长什么样（颜色、字体、布局）
- `.js` —— 网页脚本语言，让网页能交互（点击、动画、数据加载等）
- `.mjs` —— ES Module JavaScript 文件，明确表示使用 ES 模块
- `.cjs` —— CommonJS JavaScript 文件，Node.js 传统模块格式
- `.json` —— 轻量数据交换格式，程序之间传数据几乎都用它
- `.xml` —— 可扩展标记语言，用来存储和传输结构化数据
- `.wasm` —— WebAssembly 二进制格式，让 C++/Rust 等语言写的程序能在浏览器里跑
- `.svg` —— 矢量图格式，也常直接嵌入网页
- `.webmanifest` —— PWA 应用清单文件，定义可安装网页应用
- `.map` —— Source Map 源码映射文件，把压缩后的 JS 映射回源码
- `.pcap` / `.pcapng` —— 网络抓包文件，Wireshark 抓包后的数据
- `.torrent` —— BT 种子文件，记录文件分块信息和 Tracker 服务器地址

## 面试速答

### Q: .exe 和 .msi 有什么区别？
A: .exe 是可执行程序，双击直接运行；.msi 是 Windows 安装包格式，双击后启动安装向导，由 Windows Installer 服务统一管理安装、卸载、升级，更适合企业批量部署。

### Q: .dll、.so、.dylib 有什么区别？
A: 三者都是动态链接库，但平台不同：.dll 用于 Windows，.so 用于 Linux，.dylib 用于 macOS。它们都包含可被多个程序共享的代码，程序运行时动态加载。

### Q: .jpg 和 .png 该用哪个？
A: .jpg 适合照片类图片，有损压缩、体积小；.png 适合图标、截图，无损压缩、支持透明背景。需要透明效果或锐利边缘用 png，需要小体积存照片用 jpg。

### Q: .tar 和 .tar.gz 有什么区别？
A: .tar 只是把多个文件打包成一个文件，不做压缩；.tar.gz 是先打包成 .tar 再用 gzip 压缩，既打包又压缩。Linux 下源码分发常采用 .tar.gz。

### Q: .py 和 .pyc 有什么关系？
A: .py 是 Python 源代码文件，人类可读；.pyc 是 Python 解释器编译后的字节码文件，运行时加载更快。解释器会自动生成 .pyc，放在 `__pycache__` 目录下。
