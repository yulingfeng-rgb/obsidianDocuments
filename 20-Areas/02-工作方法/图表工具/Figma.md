# Figma 使用指南

> Figma 是一款基于云的协作设计工具，可在浏览器中绘制 UI/UX、架构图、流程图、时序图等，支持实时多人协作、组件库复用和 AI 集成。本文介绍 Figma 的界面布局、常用快捷键、图表绘制和高级功能，是设计和开发团队常用的"在线设计台"。

**关键词**：Figma、协作设计、UI/UX、组件库、实时协作

## 抽象类比

Figma 就像一张永远铺在云上的"在线设计台"。无论你在哪台电脑、和谁一起画，打开浏览器就能看到同一张画布——你画一笔，队友立刻看见，不用再传来传去发文件。它既能画 UI 界面，也能画架构图、流程图，组件画一次就能反复拖拽复用，就像设计零件库。对程序员来说，它常被用来画系统架构图和流程图，比 PPT 灵活、比专业设计软件轻量。

## 一、快速开始

- 网页版：https://www.figma.com/ （无需安装，浏览器直接使用）
- 桌面应用：https://www.figma.com/downloads/

## 二、界面布局

```
顶部工具栏（工具、缩放、分享）
├── 左侧图层面板
├── 中间画布区域
└── 右侧属性面板
```

## 三、常用快捷键

- `V`：选择工具
- `R`：矩形
- `O`：椭圆
- `L`：线条
- `T`：文字
- `K`：钢笔
- `Ctrl+D`：复制
- `Ctrl+G`：编组
- `Ctrl+Shift+G`：取消编组
- `Space+拖拽`：平移画布
- `滚轮`：缩放

## 四、常用图表

### 架构图 / 分层图

1. 矩形表示模块，文字说明
2. 线条连接模块
3. 不同颜色区分层级

### 流程图

- 椭圆：开始/结束
- 矩形：处理步骤
- 菱形：判断
- 箭头连接

### 时序图

1. 垂直线表示对象
2. 水平箭头表示消息
3. 添加时间标签

## 五、高级功能

### 组件库

选中元素 → 右键 → 创建组件 → 从资产面板拖拽复用

### 自动布局

选中多个元素 → `Shift+A` → 设置间距和对齐

### 样式系统

选中元素 → 属性面板 → 创建样式 → 命名后一键应用

### 导出

- 选中元素 → 右键 → 导出为 PNG/SVG/PDF
- 支持透明背景

## 六、协作功能

- **实时协作**：多人同时编辑
- **评论**：在画布上添加评论
- **分享链接**：设置权限后分享
- **版本历史**：自动保存，可回溯
