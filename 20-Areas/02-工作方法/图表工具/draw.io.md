# draw.io 使用指南

> draw.io（diagrams.net）是一款免费开源的图表绘制工具，支持桌面应用和在线使用，可离线工作，导出格式灵活。本文介绍 draw.io 的界面布局、常用快捷键、图表绘制和高级功能，适合画架构图、流程图、网络拓扑图、UML 图等。

**关键词**：draw.io、图表绘制、开源工具、流程图、架构图

## 抽象类比

draw.io 就像一块"在线白板"，上面摆着各种形状的贴纸——矩形、圆柱、云形、菱形……你想画什么图就拖什么形状，再用线一连，一张架构图、流程图、网络拓扑图就出来了。和 Mermaid"用文字画图"不同，draw.io 是"用鼠标画图"，所见即所得；和 Figma 不同，它完全免费开源、能离线使用，内置大量专业形状库（UML、ER、网络设备），画技术文档的图最合适。

## 一、快速开始

- 桌面应用：https://github.com/jgraph/drawio-desktop/releases
- 在线版：https://app.diagrams.net/
- VS Code：安装扩展 `Draw.io Integration`，创建 `.drawio` 文件双击打开

## 二、界面布局

```
顶部工具栏
├── 左侧形状库
├── 中间画布
└── 右侧属性面板
```

## 三、常用快捷键

- `Ctrl+N`：新建文件
- `Ctrl+S`：保存
- `Ctrl+Z/Y`：撤销/重做
- `Ctrl+D`：复制并移动
- `Ctrl+G`：编组
- `Ctrl+Shift+G`：取消编组
- `Delete`：删除

## 四、常用图表

### 架构图

- 矩形：模块/组件
- 圆柱：数据库
- 云形：云服务
- 线条连接，不同颜色区分层级

### 流程图

- 椭圆：开始/结束
- 矩形：处理步骤
- 菱形：判断
- 箭头连接

### 网络拓扑图

- 设备形状库：路由器、交换机、服务器
- 连接线表示网络关系

### UML 图

- 类图、时序图、用例图等
- 内置 UML 形状库

### ER 图

- 实体、属性、关系
- 内置 ER 形状库

## 五、高级功能

### 样式系统

- 填充颜色、边框颜色、线条样式
- 创建自定义样式，一键应用

### 模板库

- 内置多种模板（架构图、流程图、网络图等）
- File → New → 选择模板

### 导出格式

- PNG、SVG、PDF、HTML
- 支持透明背景
- 可导出为 `.drawio.png` 嵌入文档

## 六、对比 Mermaid / Figma

- draw.io：图形编辑器，优势是功能全面、离线可用，适合复杂图表，学习成本中等，免费开源
- Mermaid：代码生成图，优势是版本管理、快速，适合 Markdown 嵌入，学习成本低，免费开源
- Figma：协作设计，优势是实时协作、美观，适合 UI/架构图，学习成本中等，免费版有限
