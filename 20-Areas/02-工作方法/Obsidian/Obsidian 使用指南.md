# Obsidian 配置指南

> 本文档记录 Obsidian 的配置建议，优化知识库使用体验。

---

## ⚙️ 核心配置

### 1. 文件和链接

- **附件文件夹**: `99-Assets/images`
- **默认编辑器**: 源代码模式（推荐）
- **自动保存**: 开启
- **实时预览**: 开启

### 2. 外观

- **主题**: Border（已安装）
- **字体**: 推荐等宽字体（代码友好）
- **界面语言**: 中文

### 3. 核心插件（必开）

- ✅ **文件回收站**: 防止误删
- ✅ **文件资源管理器**: 浏览文件树
- ✅ **全局搜索**: 快速查找
- ✅ **双向链接**: 知识关联
- ✅ **标签面板**: 标签管理
- ✅ **大纲**: 文档导航
- ✅ **日记**: 每日记录
- ✅ **模板**: 快速插入

### 4. 社区插件（已安装）

#### Templater（模板增强）
- **模板文件夹**: `90-Templates`
- **触发方式**: 快捷键 `Ctrl+T`
- **自动触发**: 创建新文件时

**配置步骤**：
1. 设置 → 第三方插件 → Templater
2. Template folder location: `90-Templates`
3. 设置快捷键: `Ctrl+T`
4. 勾选 "Trigger Templater on new file creation"

#### Excalidraw（绘图）
- **绘图保存位置**: `Excalidraw`
- **快捷键**: `Alt+E` 新建绘图

**配置步骤**：
1. 设置 → 第三方插件 → Excalidraw
2. Drawing folder location: `Excalidraw`
3. 设置快捷键

## 🎯 工作流建议

### 日常使用

1. **收集想法** → 写入 `00-Inbox`
2. **创建日记** → `Ctrl+T` 选择日记模板
3. **创建项目** → `Ctrl+T` 选择项目模板
4. **整理笔记** → 从 Inbox 移到对应目录
5. **建立链接** → 使用 `[[双向链接]]`

### 每周回顾

- [ ] 清理 `00-Inbox`，整理到新位置
- [ ] 更新 `MOC.md` 导航页
- [ ] 检查 Projects 进度
- [ ] 归档已完成项目

### 标签系统

**推荐标签结构**：

```
#项目/比赛          # 项目分类
#技术/AI           # 技术领域
#状态/进行中        # 任务状态
#状态/已完成
#类型/概念          # 内容类型
#类型/教程
```

## 🔧 高级配置

### 1. 热键设置

推荐快捷键：
- `Ctrl+T`: Templater 插入模板
- `Ctrl+Shift+T`: 插入当前时间
- `Alt+E`: 新建 Excalidraw 绘图
- `Ctrl+O`: 快速打开笔记

### 2. CSS 代码片段

如需自定义样式，添加到 `.obsidian/snippets/` 目录

### 3. Git 集成（推荐）

使用 Git 跟踪笔记变更：
```bash
git init
git add .
git commit -m "初始化知识库"
```

## 🐛 常见问题

### Q: 模板不生效？
A: 检查 Templater 插件是否启用，模板文件夹路径是否正确

### Q: 双向链接找不到笔记？
A: 确保笔记名完全匹配，包括路径

### Q: 如何批量重命名？
A: 使用 Obsidian 的重命名功能，会自动更新链接
