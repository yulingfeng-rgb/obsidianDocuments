## 一、介绍

### 1.1 什么是 Trello

Trello 是一款基于看板的团队协作工具，用于管理项目、任务和流程。

**特点**：
- 可视化看板
- 拖拽操作
- 团队协作
- 跨平台

**应用场景**：
- 项目管理
- 任务跟踪
- 团队协作
- 个人待办
- 内容规划
- 敏捷开发

### 1.2 与其他工具对比

| 工具 | 优势 | 劣势 |
|------|------|------|
| Trello | 简单直观、协作强 | 功能有限 |
| Notion | 功能全面、灵活 | 学习曲线陡 |
| Jira | 专业、强大 | 学习成本高 |

## 三、基本概念

### 3.1 核心概念

| 概念 | 说明 | 示例 |
|------|------|------|
| 看板（Board） | 项目或主题 | 操作系统比赛 |
| 列表（List） | 阶段或状态 | 待办、进行中、已完成 |
| 卡片（Card） | 具体任务 | 完成 NPU 驱动 |
| 标签（Label） | 分类或优先级 | 高优先级、Bug |
| 成员（Member） | 团队成员 | 张三、李四 |

### 3.2 看板结构

```
看板
├── 列表 1：待办
│   ├── 卡片 1
│   ├── 卡片 2
│   └── 卡片 3
├── 列表 2：进行中
│   ├── 卡片 4
│   └── 卡片 5
└── 列表 3：已完成
    └── 卡片 6
```

## 四、看板创建

### 4.1 创建看板

**步骤**：
1. 登录 Trello
2. 点击"创建新看板"
3. 输入看板名称
4. 选择可见性（私有/团队/公开）
5. 点击"创建"

### 4.2 创建列表

**步骤**：
1. 在看板右侧点击"添加另一个列表"
2. 输入列表名称
3. 按 Enter 确认

**常用列表**：
```
待办 → 进行中 → 已完成
```

或

```
收件箱 → 待处理 → 开发中 → 测试中 → 已完成
```

### 4.3 创建卡片

**步骤**：
1. 点击列表下方的"添加卡片"
2. 输入卡片标题
3. 按 Enter 确认
4. 可继续添加多张卡片

## 五、卡片管理

### 5.1 卡片详情

**点击卡片打开详情**：

| 功能 | 说明 |
|------|------|
| 标题 | 任务名称 |
| 描述 | 任务详细说明 |
| 成员 | 分配给谁 |
| 标签 | 分类和优先级 |
| 清单 | 子任务列表 |
| 截止日期 | 任务截止时间 |
| 附件 | 相关文件 |
| 评论 | 讨论和反馈 |

### 5.2 移动卡片

**拖拽方式**：
1. 鼠标悬停在卡片上
2. 按住鼠标左键
3. 拖拽到目标列表
4. 释放鼠标

**快捷方式**：
- 点击卡片
- 点击"移动"
- 选择目标列表和位置

### 5.3 编辑卡片

**添加描述**：
1. 打开卡片
2. 点击"描述"
3. 输入详细描述
4. 支持 Markdown 格式

**添加成员**：
1. 打开卡片
2. 点击"成员"
3. 选择团队成员
4. 成员会收到通知

**添加标签**：
1. 打开卡片
2. 点击"标签"
3. 选择或创建标签
4. 设置颜色

### 5.4 清单（子任务）

**创建清单**：
1. 打开卡片
2. 点击"清单"
3. 输入清单标题
4. 添加清单项

**示例**：
```
清单：NPU 驱动开发
- [ ] 环境配置
- [ ] 驱动框架
- [ ] 模型加载
- [ ] 推理测试
- [ ] 性能优化
```

### 5.5 截止日期

**设置截止日期**：
1. 打开卡片
2. 点击"截止日期"
3. 选择日期和时间
4. 保存

**提醒**：
- 到期前会收到提醒
- 可设置多个提醒

## 六、高级功能

### 6.1 过滤器

**使用过滤器**：
1. 点击看板右上角"过滤器"
2. 选择过滤条件
3. 查看筛选结果

**过滤条件**：
- 成员
- 标签
- 截止日期
- 关键词

### 6.2 看板模板

**使用模板**：
1. 创建新看板
2. 选择"从模板创建"
3. 选择模板类型
4. 自定义内容

**常用模板**：
- 项目管理
- 敏捷开发
- 内容规划
- 个人待办

### 6.3 自动化（Butler）

**创建自动化规则**：
1. 点击看板菜单
2. 选择"自动化"
3. 创建规则

**示例规则**：
```
当卡片移动到"已完成"列表时
  → 标记为完成
  → 发送通知
```

### 6.4 电源-ups（插件）

**启用 Power-Ups**：
1. 点击看板菜单
2. 选择"Power-Ups"
3. 浏览和启用

**常用 Power-Ups**：
- Calendar（日历视图）
- Card Aging（卡片老化）
- Custom Fields（自定义字段）
- Google Drive（Google 云盘集成）

### 6.5 团队协作

**邀请成员**：
1. 点击看板菜单
2. 选择"邀请"
3. 输入邮箱或用户名
4. 发送邀请

**权限设置**：
- 管理员：完全控制
- 普通成员：编辑权限
- 观察者：只读权限
