## 一、介绍

### 1.1 什么是 draw.io

draw.io 是一款免费开源的图表绘制工具，支持桌面和在线使用。

**特点**：
- 免费开源
- 离线可用
- 功能强大
- 导出灵活

**应用场景**：
- 系统架构图
- 流程图
- 网络拓扑图
- UML 图
- ER 图
- 思维导图

### 1.2 与其他工具对比

| 工具 | 优势 | 劣势 |
|------|------|------|
| draw.io | 免费、离线可用、功能强 | 协作弱 |
| Figma | 协作强、美观 | 需要网络 |
| Mermaid | 代码生成、版本控制 | 定制性差 |
| Excalidraw | 手绘风格 | 功能简单 |

## 二、架构图绘制

### 2.1 架构图示例

```
┌──────────────────────────────────────┐
│        Application Layer             │
│  ┌────────────┐  ┌────────────┐    │
│  │  Web UI    │  │ Mobile App │    │
│  └────────────┘  └────────────┘    │
└──────────────────────────────────────┘
                ↓
┌──────────────────────────────────────┐
│       Business Logic Layer           │
│  ┌────────────┐  ┌────────────┐    │
│  │ Service A  │  │ Service B  │    │
│  └────────────┘  └────────────┘    │
└──────────────────────────────────────┘
                ↓
┌──────────────────────────────────────┐
│          Data Layer                  │
│  ┌────────────┐  ┌────────────┐    │
│  │  Database  │  │   Cache    │    │
│  └────────────┘  └────────────┘    │
└──────────────────────────────────────┘
```

### 2.2 draw.io 绘制步骤

#### 步骤 1：创建背景层

1. 从左侧拖拽 **Rectangle** 到画布
2. 设置填充颜色：`#F5F5F5`（浅灰）
3. 调整大小覆盖整个层级
4. 添加文字：`Application Layer`

#### 步骤 2：添加模块

1. 拖拽 **Rounded Rectangle** 到背景层内
2. 设置填充：`#E3F2FD`（浅蓝）
3. 添加模块名称：`Web UI`
4. 按 `Ctrl+D` 复制其他模块

#### 步骤 3：添加箭头

1. 从左侧 **Arrows** 库拖拽箭头
2. 连接上下层模块
3. 设置箭头颜色：`#333333`
4. 设置线条粗细：`2px`

#### 步骤 4：对齐和分布

1. 选中同一层的模块
2. 顶部菜单 → **排列** → **对齐**
3. 选择 **水平居中** 或 **垂直居中**
4. 选择 **分布** → **水平等距**

### 2.3 配色方案

| 层级 | 背景色 | 模块色 | 用途 |
|------|--------|--------|------|
| 表示层 | #E3F2FD | #BBDEFB | UI、API |
| 业务层 | #E8F5E9 | #C8E6C9 | 服务、逻辑 |
| 数据层 | #FFF3E0 | #FFE0B2 | 数据库、缓存 |
| 外部系统 | #F3E5F5 | #E1BEE7 | 第三方服务 |

```
┌──────────────────────────────────────┐
│      Application Layer               │
│  Tennis Robot / LeRobot              │
└──────────────────────────────────────┘
┌──────────────────────────────────────┐
│        Runtime Layer                 │
│  ROS2 / Middleware / Scheduler       │
└──────────────────────────────────────┘
┌──────────────────────────────────────┐
│         Kernel Layer                 │
│  Memory / Task / IPC / Filesystem    │
└──────────────────────────────────────┘
┌──────────────────────────────────────┐
│         Driver Layer                 │
│  NPU / UART / USB / Camera           │

┌──────────────────────────────────────┐
│        Hardware Layer                │
│        RK3588 Board                  │
└──────────────────────────────────────┘
```

### 3.2 draw.io 绘制步骤

#### 步骤 1：创建分层容器

1. 拖拽 5 个 **Rectangle** 垂直排列
2. 设置间距：`20px`
3. 每层设置不同背景色

#### 步骤 2：添加层内组件

1. 在每层内添加 **Rounded Rectangle**
2. 水平排列，间距 `15px`
3. 使用相同色系不同深浅

#### 步骤 3：添加层间箭头

1. 使用 **Arrow** 连接各层
2. 垂直向下
3. 添加文字标签（接口名称）

#### 步骤 4：添加说明

1. 每层右侧添加 **Text**
2. 说明该层职责
3. 字体：`14px`，灰色

### 3.3 设计要点

- ✅ 层与层之间清晰分隔
- ✅ 使用容器（Container）组织
- ✅ 层间箭头标注接口
- ✅ 颜色层次分明

## 四、流程图绘制

### 4.1 流程图示例（UART 驱动初始化）

```
     ┌──────────┐
     │  Start   │
     └──────────┘
          ↓
     ┌──────────┐
     │ Clock    │
     │ Config   │
     └──────────┘
          ↓
     ┌──────────┐
     │ GPIO     │
     │ Config   │
     └──────────┘
          ↓
    ┌────────────┐
    │ UART Init  │
    │ Baud Rate  │
    └────────────┘
          ↓
    ┌──────────────┐
    │ Interrupt?   │
    └──────────────┘
       ↓        ↓
     Yes        No
       ↓        ↓
  ┌────────┐ ┌────────┐
  │Enable  │ │Polling │
  │IRQ     │ │Mode    │
  └────────┘ └────────┘
       ↓        ↓
  ┌──────────────┐
  │    End       │
  └──────────────┘
```

### 4.2 draw.io 绘制步骤

#### 步骤 1：创建节点

1. **开始/结束**：从 **Flowchart** 库拖拽 **Terminator**（椭圆）
   - 填充：`#C8E6C9`（绿色）
   
2. **处理步骤**：拖拽 **Process**（矩形）
   - 填充：`#BBDEFB`（蓝色）
   
3. **判断节点**：拖拽 **Decision**（菱形）
   - 填充：`#FFF9C4`（黄色）

#### 步骤 2：连接节点

1. 鼠标悬停图形，拖拽蓝色箭头
2. 连接到下一个节点
3. 设置箭头样式：**Classic Arrow**

#### 步骤 3：标注分支

1. 双击箭头添加文字
2. Yes/No 分支标注
3. 文字位置调整到箭头旁边

#### 步骤 4：对齐和美化

1. 选中所有节点
2. **排列** → **对齐** → **水平居中**
3. **排列** → **分布** → **垂直等距**
4. 统一圆角、阴影

### 4.3 流程图规范

| 元素 | 图形 | 颜色 | 说明 |
|------|------|------|------|
| 开始/结束 | Terminator | 绿/红 | 流程起止 |
| 处理步骤 | Process | 蓝 | 操作、处理 |
| 判断 | Decision | 黄 | 条件分支 |
| 数据 | Data | 橙 | 输入输出 |
| 文档 | Document | 白 | 文档输出 |

```
         ┌──────────┐
         │  Parse   │
         └──────────┘
        ↙          ↘
  ┌──────────┐   ┌──────────┐
  │ Semantic │   │   Type   │
  │ Analysis │   │  Check   │
  └──────────┘   └──────────┘
        ↘          ↙
      ┌──────────────┐
      │ Optimization │
      └──────────────┘
            ↓
      ┌──────────┐
      │Code Gen  │
      └──────────┘
            ↓
      ┌──────────┐
      │ Linking  │
      └──────────┘
```

### 5.2 draw.io 绘制步骤

3. 填充：`#E3F2FD`

1. 使用 **Arrow** 连接

3. 确保无环

#### 步骤 3：分层布局

1. 第一层：无依赖任务
2. 第二层：依赖第一层
3. 使用 **Grid** 对齐

#### 步骤 4：标注关键路径

1. 选中关键路径节点
2. 设置填充：`#FF5252`（红色）
3. 箭头加粗：`3px`

### 5.3 DAG 图设计要点

- ✅ 从左到右或从上到下
- ✅ 避免交叉线
- ✅ 标注关键路径
- ✅ 节点大小统一

                    ↓           │
             ┌─────────────┐   │
             │    IDLE     │←──┘

### 6.2 draw.io 绘制步骤

### 9.6 常见问题

#### 问题 1：图形对齐不精确

**解决**：
1. 使用 **对齐工具**
2. 开启 **网格对齐**（视图 → 网格）
3. 使用 **智能对齐**（视图 → 智能对齐）

#### 问题 2：箭头连接不准确

**解决**：
1. 使用图形连接点（蓝色小点）
2. 调整连接点位置
3. 使用 **重新连线** 工具

#### 问题 3：导出图片模糊

**解决**：
1. 导出时选择 **高分辨率**（2x 或 3x）
2. 使用 **SVG** 格式（矢量无损）
3. 调整画布大小
